# 1Win Signal Bot

Bu Telegram bot 1Win o‘yinlari uchun signal (bashorat) generatsiya qiladi:
- **Lucky Jet** uchun koeffitsiyentlar bashorati
- **Mines** uchun xavfsiz joylarni aniqlovchi tasvir

## Funksiyalar:
- Telegram orqali ishlaydi
- Foydalanuvchi tugmalar orqali o‘yin tanlaydi
- Lucky Jet uchun: koeffitsiyentlar + bashorat va ehtimollik
- Mines uchun: xavfli va xavfsiz joylar tasviri
- 1Win promo kodi bilan bog‘lanadi (masalan: `Nozim`)
